# Проект Mesto

Опубликованная версия: https://egor12344321.github.io/mesto-production/

## Установка и запуск

#### Склонировать репозиторий
```bash
git clone https://github.com/Egor12344321/mesto-ad.git
cd mesto-ad
```
#### Установить зависимости
```bash
npm install
```

#### Запустить проект в режиме разработки
```bash
npm run dev
```

#### Собрать проект
```bash
npm run build
```

#### Опубликовать проект
```bash
npm run deploy
```
